# Jchat 用户状态与频道在线人数设计

日期：2026-08-10

## 目标

为 Jchat 增加实时用户状态、频道在线人数与单账号单页面在线能力，并让频道详情侧栏只在频道会话中出现。

## 用户体验

### 用户状态

- 个人设置提供四种可选状态：在线、忙碌、离开、隐身。
- 离线不是可手动选择的状态，而是由服务器根据实时连接自动判断。
- 状态偏好写入 SQLite，用户重新登录后继续使用上次选择。
- 用户设置为隐身后：
  - 本人仍能在个人设置中看到“隐身”。
  - 其他用户查看其资料时只看到“离线”。
  - 不计入任何频道的在线人数。
- 在线、忙碌和离开用户只要保持有效连接，均计为在线。
- 状态控件同时使用圆点和文字，不以颜色作为唯一信息来源。

### 频道在线人数

- 选中频道后，右侧频道详情显示频道名称和“在线 X 人”。
- 人数统计所有拥有该频道访问权限且当前在线的非隐身用户，不要求这些用户正在打开该频道。
- 公共频道对所有用户开放，因此统计所有当前在线且非隐身的用户。
- 私有频道只统计频道创建者和已获邀请的成员。
- 同一账号只计一次。
- 登录、退出、断线、状态切换、频道成员关系变化时，人数实时刷新。

### 侧栏显示规则

- 只有当前视图为频道会话且已经选中频道时，显示频道详情 `aside`。
- 未选择频道时隐藏 `aside`。
- 私聊视图隐藏 `aside`。
- 隐藏后中间聊天区域自动占用释放的宽度，不保留空白列。
- 现有响应式规则继续生效；小屏幕可以保持隐藏详情侧栏。

### 用户资料卡

- 点击其他用户头像打开资料卡时，在用户名附近显示其当前有效状态。
- 在线、忙碌、离开按真实状态显示。
- 隐身和真实离线统一显示为“离线”，客户端无法据此区分。
- 已打开的资料卡在目标用户状态变化时实时更新。

### 单账号单页面在线

- 每个账号同一时刻只允许一个有效页面连接。
- 新页面完成认证后，新连接保留，服务器使该账号先前的页面会话失效。
- 旧页面立即收到“账号已在其他页面登录”的提示，清理本地登录态并返回登录页。
- 被替换的旧连接立即停止接收聊天事件，也不再参与在线人数统计。
- 服务端执行互斥，不能只依赖客户端退出，以免旧页面继续调用受保护接口。

## 技术设计

### 数据层

在 `users` 表增加 `presence_status` 字段（默认值为 `online`）和当前登录会话标识字段。服务器只接受以下状态：

- `online`
- `busy`
- `away`
- `invisible`

数据库迁移兼容现有 SQLite 数据，不删除或重建用户数据。资料更新逻辑增加该字段的白名单与枚举校验。

### 实时连接层

Socket.IO 服务维护内存态：

- 当前账号对应的唯一有效 socket。
- 已认证 socket 对应的用户 ID。
- 用户的实时连接状态。

每次登录成功后生成不可预测的独立会话标识，将其写入用户当前会话字段并放入 JWT。所有 HTTP 鉴权和 Socket 认证都必须确认 JWT 中的会话标识仍与数据库一致。新登录会覆盖旧标识，因此旧令牌立即失效。

认证新 socket 时，服务器先登记新连接，再向旧连接发送会话替换事件并主动断开旧连接。断开事件只有在断开的 socket 仍是该账号当前登记连接时才会把用户标记为离线，避免旧连接的延迟断开覆盖新连接。

服务器在以下事件后广播状态或人数变化：

- socket 认证成功。
- socket 断开。
- 用户更改状态偏好。
- 私有频道成员新增或移除。

### 在线人数计算

在线人数由服务器计算，客户端不自行推断。计算步骤：

1. 查询或缓存频道可访问成员集合。
2. 筛选存在当前有效 socket 的用户。
3. 排除 `presence_status = invisible` 的用户。
4. 按用户 ID 去重后返回数量。

公共频道可直接从当前有效连接集合中过滤隐身用户。私有频道按成员权限集合求交集。

客户端选中频道时订阅该频道的在线人数更新；离开频道、进入私聊或取消选择时停止展示。服务端广播可以携带频道 ID 与人数，客户端只更新当前选中频道对应的数据。

### HTTP 与隐私边界

- 个人资料接口返回经过隐私处理的 `effective_status`，不向其他用户泄露 `invisible`。
- 当前用户读取自己的设置时可获得真实 `presence_status`。
- 修改状态必须通过已认证的个人资料接口或专用状态接口。
- 单页面互斥不仅断开 socket，还要用数据库中的当前会话标识使旧 JWT 对所有受保护接口失效。

## 前端改动

- 设置表单加入状态选择及保存反馈。
- 资料卡加入状态行。
- 频道详情加入带 `aria-live="polite"` 的在线人数文本。
- 工作区根据 `channel + selectedChannel` 状态切换详情侧栏和网格列。
- 监听状态、频道人数和会话替换事件。
- 收到会话替换事件后显示统一风格提示，并执行安全退出流程。
- 登录令牌使用标签页隔离的存储，避免多个标签页共享同一个令牌；迁移时兼容并清理旧的共享存储数据。

## 异常与边界处理

- 网络短暂断开期间显示离线；Socket.IO 重连并重新认证后恢复保存的状态。
- 服务重启会清空内存连接态；客户端重连后重新建立在线状态。
- 无权访问私有频道的客户端不能订阅或读取其在线人数。
- 状态字段出现未知值时，服务器回退为 `online`，对外资料回退为 `offline`，避免泄露或界面异常。
- 新页面认证失败时不踢出旧页面；只有新页面认证成功后才替换旧连接。

## 验收标准

1. 频道选中时显示正确的在线人数，私聊和未选频道时不显示详情侧栏，也没有空白列。
2. 在线、忙碌、离开、隐身可保存并在重新登录后恢复。
3. 隐身用户在其他人的资料卡中显示离线，且不计入频道人数。
4. 私有频道人数只包含拥有访问权限的在线成员。
5. 新页面登录同一账号后，旧页面立即提示并退出，旧连接不能继续发送消息或调用受保护接口。
6. 用户上线、下线或切换状态时，相关频道在线人数和已打开资料卡实时更新。
7. 桌面与现有响应式尺寸下布局无右侧空白或横向滚动条。
