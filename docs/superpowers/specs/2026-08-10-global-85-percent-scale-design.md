# Jchat 全页面 85% 缩放与页脚可见性设计

## 目标

所有桌面页面统一缩小 15%，同时保证聊天页脚在常见笔记本视口中无需页面缩放或向下滚动即可看到。移动端保持 100%，避免触控目标和正文过小。

## 设计

- 桌面断点为 `min-width: 769px`。
- 聊天、登录、注册、后台和后台登录页面在桌面统一使用 `zoom: .85`，并用根元素宽高补偿保证缩放后仍完整铺满视口。
- 聊天壳体使用 `calc(100dvh / .85)` 补偿后的动态视口高度，顶部栏、工作区、页脚共同占满可用高度。
- 工作区取消导致页脚被挤出视口的固定 `590px` 最小高度，改为可收缩的 `min-height: 0`。
- 移动端不缩放，继续使用既有移动布局和安全区规则。
- 页面不得产生横向滚动条，页脚的可编辑能力保持不变。

## 验收标准

1. 所有生产页面在桌面端均为 85% 缩放。
2. 聊天页面在 1440×900 与 1366×768 视口中可以看到页脚，最右侧和底部不得出现缩放空白。
3. 聊天工作区仍铺满剩余空间，消息列表可正常滚动。
4. 768px 及以下页面保持 100% 缩放。
5. 自动化测试与真实浏览器验证通过。
